# 训练预算与目标类别过滤

修正日期：2026-11-13。修改位置：`D:/GNNAttackReaserch/abp`；学习版目录没有改动。

## 1. 数量定义

生成时必须且只能给出一种过滤前预算：

- `--rate 3`：`floor(N_train×3/100)`，其中N_train为**注入前原训练节点集合的数量**，不含验证、测试和本次追加的附着位置。
- `--vs_number 16`：显式指定16个候选位置，数值本身不变；`--vs-number`是连字符别名。

两项默认均为None，只训练或重载已有样本时不必传入。未指定预算、同时指定两项、非正数、非有限比例、取整为零或候选不足会拒绝生成。

Cora当前划分仍为原项目的20%训练、10%验证、20%测试，不修改划分比例。原训练集合有541个节点，因此rate=3得到16个候选位置，**不再是81个**。这里对齐训练数据作为分母，不表示已更换成DMGNN论文中80%训练划分。

## 2. 先选样，再过滤，不补选

按LoSplit等作者入口的实际顺序：

1. 根据预算和class-sampling选取候选位置。
2. 删除其中原标签等于target的位置。
3. 不重新选取其他位置补足预算。被删位置继续保留在普通未标注池中。
4. 只把剩余位置交给生成器fit和get_poisoned；所有方法共用这份已过滤数据。

所以vs_number和rate算出的是作者代码意义上的**选样预算**，最终实际组数可能更少。若需要过滤后仍严格等于指定值，将需要“过滤前排除或补选”这种不同规则；当前遵循用户指出的先选后滤流程。

例如本次Cora、seed10、target0、默认random：选16个，滤去3个原类别0位置，实际生成13组，新增39个节点。13个附着原节点的标签均发生改变。

来源位置：`upstream/LoSplit/UGBA_LoSplit.py`中206—230行和GTA对应入口，选取size后执行`data.y[idx_attach] != args.target_class`，再训练生成器。本轮不修改作者源码，而是在公共生成入口提前统一落实该步骤。

## 3. 类别选样模式

- 默认`--class-sampling random`：保留原全候选池无放回随机选样，再过滤原目标类别。没有改成类别均匀选样。
- 显式`--class-sampling uneven`：根据seed产生各原始类别的Dirichlet(1)权重、分配整数预算、在类内无放回选择，再执行同一目标类过滤；不重新分配被过滤的配额。

两种模式均只从原未标注候选池选择，不与原训练、验证或测试位置重叠。候选池中原目标类位置在选样前仍存在，过滤发生在选样后。

不均匀配额使用本项目明确的seed规则，借鉴DMGNN“不同类别注入不同数量”的设置；不称为作者未公开整数选样算法的逐行复现。相关公开文本已缓存于`paper/references/DMGNN_sampling_reference_20261113.html`。

原始标签仅用于生成阶段选位置和过滤；生成器的其余监督输入保持原先限制，防御不获得额外的干净标签监督。

## 4. 元数据与历史数据

`metadata.json`记录：

- `settings.budget_basis=original_train_nodes`、`settings.target_filter=after_selection_no_refill`，用于防止误复用旧规则生成的数据。
- `budget.original_train_nodes`、`requested_trigger_groups`、`filtered_target_count`、`resolved_trigger_groups`，分别是原训练数量、预算、过滤数、实际组数。
- `class_allocation.selected_source_counts_before_filter`和`poisoned_source_counts`，分别为过滤前后的原类别计数。
- `selected_nodes_before_filter`和`filtered_target_nodes`供逐位置复核；实际生成位置仍存于evaluation.pt的attached。

旧的全图3%批次及报告保留为历史记录，不修改其数值。当前generate会拒绝把旧规则数据当作新规则数据复用；重新生成请使用新目录。已有模型仍可按原数据重载评估。

## 5. 运行方式

默认random，省略class-sampling即可：

```text
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack UGBA --rate 3 --seed 10 --output-root outputs/cora_train_rate3_random --device cuda:0
uv run --locked --extra cu118 python run_defense.py --dataset Cora --attack UGBA --model GCN --methods none abp --bundle outputs/cora_train_rate3_random/data/Cora/UGBA/seed10 --output-root outputs/cora_train_rate3_random --device cuda:0
```

显式数量：把第一条的`--rate 3`替换成`--vs_number 16`。不均匀模式：增加`--class-sampling uneven`。人工修改parse默认值时，同样保持两种预算中另一项为None。

批量流程可使用相同预算：

```text
uv run --locked --extra cu118 python run_study.py --datasets Cora --models GCN GAT GraphSAGE --attacks UGBA --seeds 10 --methods none abp rigbd dshield mad prune --rate 3 --output-root outputs/cora_train_rate3_random_all --device cuda:0
```

这些参数只控制训练图注入预算，不裁剪原攻击测试集合。测试图的注入范围和各作者ASR分母继续采用原流程。
