# 代码结构与实验协议

更新日期：2026-11-11。当前协议标识为`author_original_20261111`。

下文的heldout边指训练时移去、测试时恢复的测试节点相关连接；原模型或原生模型指直接从作者源码构造的模型对象。

## 一、复用的具体范围

公开数据读取、固定划分、生成与保存样本属于本项目公共流程。从固定污染图载入后的作者参考训练、防御训练和原评估开始，复用作者模型、函数和入口语句。公共样本由DShield仓库的GTA、UGBA、DPGBA原生成器产生，各比较方法共用同一份生成器权重和训练数据。该设计评估相同污染数据上的作者防御流程；生成节点名单和随机数消耗不等同于每个作者完整仓库从头独立运行。

| 作者 | 固定提交 | 防御调用来源 |
|---|---|---|
| RIGBD | `32415022d1becebd76296b0abc1b63853093697b` | `upstream/RIGBD/defense.py`及其原模型fit |
| LoSplit | `171874c7e1dd4db4286ad5ab3423cd23871bc98e` | GTA/UGBA入口及DPGBA子目录对应入口、原LoSplit.fit、原finetune2 |
| DShield | `a1fab6a0ce52ea0c99ae5591a930a11e2da611a1` | `NodeClassificationTasks/main.py`、`defense/dshield.py` |
| MAD | `f47cef85ecc70e1946a3da79c3e5fb37723594fb` | 两个生成分支的对应入口、Detect_encoder、anomaly_detect和原模型fit |
| Prune | 同LoSplit | `help_funcs.py::prune_unrelated_edge`、原模型工厂与fit |

244个原始源码及配置文件已按固定提交的Git blob校验，`upstream`保持作者原文件。来源清单为`author_source_manifest.json`。两个`tools/build_*_calls.py`按源码行段生成调用模块，记录来源行号、哈希和允许的接口改动；`check_project.py`核对文件未变化。`Prune`调用模块只组织作者函数调用，不另写剪边公式。

LoSplit根目录与DPGBA子目录的两个Prune辅助函数已通过AST一致性检查。因此DPGBA调用模块直接导入根目录的相同原函数，避免DPGBA辅助文件中与当前函数无关的faiss导入；模型工厂仍使用DPGBA对应原目录。这一导入适配不修改作者文件或剪边计算，`check_project.py`持续核对两分支函数一致。

## 二、代码怎么走

1. `run_attack.py`调用`src/attack.py`，保存公共样本。
2. `run_defense.py`或`run_study.py`调用`src/workflow.py`。
3. 主进程读取固定样本标识，校验文件，调用原生成器重建含零权边的测试输入缓存。
4. 每个方法启动一个`author_worker.py`进程，只激活该作者目录；由`src/author_execution.py`调用对应作者模块。
5. 作者参考阶段、核心训练、测试按提取的原语句顺序执行。K与丢边率由配置替换原常量；骨架列表按用户选择参数化。
6. 保存实际模型、原指标、实际参数和训练节点列表。重新评估时恢复作者原模式与随机状态，再执行原测试片段。

测试缓存的`PacketTrigger`只把原生成器输出的新增节点和连接移动到作者要求的编号，不训练替代生成器。DShield逐节点二跳测试需要局部编号，因此额外传入原节点编号映射。旧样本中移除的零权边会从保存的生成器恢复；GAT、GraphSAGE等原实现可能忽略权重，故不能把“权重为零”和“物理删边”强行等同。训练图沿用原生成器`get_poisoned`保存的有效边。

## 三、骨架对应

| 方法 | 辅助模型 | 最终模型 |
|---|---|---|
| 无防御、ABP | ABP只处理连接，无辅助分类器 | RIGBD原GCN、GAT或GraphSage，并直接调用原fit |
| RIGBD | 与所选最终骨架相同 | 同一骨架原模型；保留原恢复fit |
| LoSplit | 固定作者LoSplit/GCN | 所选原GCN、GAT或GraphSage；调用原finetune2 |
| DShield | 对应作者骨架及内部arch适配 | 作者函数返回的对应分类器 |
| MAD | 固定GCN编码器、固定GraphSage置信度模型 | 所选骨架，保留原五个内部种子 |
| Prune | 原余弦相似性剪边 | LoSplit原骨架普通fit |

各作者同名骨架的隐藏宽度、归一化、训练轮数和检查点选择以原配置及模型函数为准；公共`--epochs`不会覆盖作者入口中写死的200、400等恢复轮数。

无防御与ABP也直接使用RIGBD原模型`fit`，保留GAT在fit中的额外参数初始化以及各骨架原模型选择。已删除本项目的自写普通训练循环，避免与原fit产生不同的训练条件。两个方法共享同一原训练接口、训练索引和公共分类参数。

## 四、标签与节点条件

- 无防御、ABP的分类训练只使用固定训练索引的标签，验证只使用验证索引。
- 作者方法接收原入口形式的完整原节点标签向量、实际污染标签和原索引。RIGBD、LoSplit的UGBA入口按原标签排除原目标类附着节点，实际监督节点列表随结果保存，不能把生成预算直接当成该作者的实际监督预算。
- RIGBD保留原目标类别参数、原出度恢复、原排序切片和恢复训练。该原实现使用已知目标类别；结果中明确记录这一条件。
- MAD两个辅助模型使用全部原节点标签，包括验证和测试节点的标签；附着位置使用污染后标签。用户已选择保留此条件。结果中的`label_condition`和CSV重复标明，不能与仅训练标签条件写成同一种监督设置。
- 2026-11-13修正后的数量参数为`--rate`与`--vs_number`二选一；`--vs-number`是连字符别名。过滤前预算为`floor(注入前原训练节点数×rate/100)`或显式vs_number，无默认预算。旧poison-fraction和poison-count入口已移除。
- `--class-sampling`默认random；uneven在原始类别之间按seed分配不同数量。两种模式都先选样，再在生成器训练前过滤原标签等于target的位置，不补选，被过滤位置回到未标注池。metadata分别记录过滤前预算、过滤数量和实际触发器组数；新样本的标签改变数等于实际附着数。
- 分层选位置及原目标类过滤需要攻击者访问相应候选的原始类别。该信息不作为生成器额外监督：生成器仍使用原训练标签及自行赋予的附着目标标签，防御也不按原始分层名单训练。

## 五、指标与耗时

原指标保存在`metrics.CA/ASR`；`CA_scope`与`ASR_scope`说明具体测试图和分母。

| 方法 | CA原定义 | ASR原定义 |
|---|---|---|
| RIGBD | 注入测试触发后的完整图，正常测试索引 | 完整图整体注入，只统计原非目标类 |
| LoSplit | 恢复heldout边、尚未注入触发的图 | 完整图整体注入，只统计原非目标类 |
| DShield | 恢复heldout边后的正常完整图 | 每个攻击测试节点单独二跳子图注入，包含原目标类 |
| MAD | 净化训练边加原heldout边，五模型平均 | 测试时再次执行原联合规则，原非目标类，五模型平均 |
| Prune | 剪边训练图加原heldout边 | 注入后再次原Prune，原非目标类 |

CA为分类正确率，ASR为预测成设定目标类别的比例。保留这些原定义后，原ASR表存在测试条件差异，论文中须同时列出该表；不能把不同测试图和分母的值解释成严格统一协议排名。

计时在数据已放到设备后开始，GPU计时前后同步。`model_build_seconds`为方法所需准备和最终训练；`prediction_seconds`为作者原评估；`reference_seconds`独立列出参考阶段；`author_execution_seconds`记录整个提取入口耗时。RIGBD、LoSplit的无防御参考训练单列，DShield的污染准备模型和MAD辅助模型属于防御所需工作，计入建立模型时间。MAD总时间包含五次最终训练，结果保留`internal_model_count=5`。数据读取、缓存生成、模型保存和进程启动不计入`model_build_seconds`。

LoSplit原GPU划分存在NumPy转换报错，本轮使用CPU成功核验。CPU与GPU结果可分别检验流程，耗时比较必须统一硬件、设备和重复次数。本轮并发进行接口核验，日志时间用作运行记录，不作为论文速度排名。

## 六、产物与完整性

每个方法目录保存`request.json`、`effective_parameters.json`、`result.json`、`model.pt`。MAD检查点包含五个最终模型和两个辅助模型、原熵阈值；其他原方法保存实际返回模型。`verify_results.py`在各作者独立进程中重载，使用相同设备和评估随机状态，核对CA、ASR，容差为1e-7。失败记录保留原错误；批量脚本继续其他方法，最终以非零退出码报告未完成。

旧协议的代码、说明及结果见`paper/archive`和原`outputs`，当前核验明确跳过旧协议模型。
