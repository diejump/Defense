# 运行命令和参数

当前版本：2026-11-11。所有命令从项目根目录执行，也可在编辑器里修改`src/config.py`中`add_argument(..., default=...)`，然后运行对应脚本。列表参数直接写成例如`default=["none", "abp", "rigbd", "dshield", "mad", "prune"]`。

2026-11-13修正：显式`--rate`与`--vs_number`二选一；rate的分母为注入前原训练节点数。`class-sampling`默认random；两种模式都先选后滤原目标类，不补选，在生成器训练前完成。完整定义见[数量与类别选样](数量与类别选样_20261113.md)。只训练或重载已有样本时可不传数量参数。

## 一、执行顺序

```text
uv sync --locked --extra cu118
uv run --locked --extra cu118 python check_project.py
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack UGBA --seed 10 --vs-number 40 --output-root outputs/new_run
uv run --locked --extra cu118 python run_defense.py --dataset Cora --attack UGBA --model GCN --methods none abp rigbd dshield mad prune --output-root outputs/new_run --device cuda:0
uv run --locked --extra cu118 python run_defense.py --dataset Cora --attack UGBA --model GCN --methods losplit --bundle outputs/new_run/data/Cora/UGBA/seed10 --output-root outputs/losplit_cpu --device cpu
uv run --locked --extra cu118 python verify_results.py --output-root outputs/new_run
uv run --locked --extra cu118 python verify_results.py --output-root outputs/losplit_cpu
uv run --locked --extra cu118 python summarize.py --output-root outputs/new_run
```

40是本条命令显式选择的过滤前预算。若希望使用原训练集1%预算，将`--vs-number 40`替换为`--rate 1`，Cora原训练节点541个，预算为5组；过滤后实际数量可能更少。两个参数不能同时提供，也不能都省略。

LoSplit固定版本源码的`split_node`直接用NumPy处理GPU标签，当前已跑通Cora/UGBA的原CPU流程。其他六个比较项已在Cora/UGBA、种子10、三种骨架上完成GPU训练与重载核验；其余数据/攻击组合尚未完成端到端验证。做耗时对比时，将所有方法设置为同一设备；本轮CPU LoSplit与GPU其他方法的时间不合并排名。

### 不比较LoSplit时的最小运行命令

下面自动生成Cora/UGBA样本，执行三种骨架的六个比较项，并汇总结果：

```text
uv run --locked --extra cu118 python run_study.py --datasets Cora --models GCN GAT GraphSAGE --attacks UGBA --seeds 10 --methods none abp rigbd dshield mad prune --rate 3 --class-sampling uneven --output-root outputs/cora_without_losplit --device cuda:0
uv run --locked --extra cu118 python verify_results.py --output-root outputs/cora_without_losplit
```

本条显式指定`--rate 3`，Cora为16个过滤前候选位置，实际附着数以过滤结果为准。`none`为无防御对照。当前默认方法列表仍包含LoSplit，所以省略LoSplit需要显式传入以上`--methods`，或人工修改`src/config.py`的`DEFAULT_METHODS`。

省略LoSplit可排除已确认的LoSplit原GPU转换、DPGBA下GAT/GraphSAGE恢复接口问题。其他方法的全数据/全攻击组合仍需逐项验证；DPGBA部分原模型的一轮fit检查不能代替完整攻击生成、防御和评估实验。

## 二、服务器批量入口

```text
uv run --locked --extra cu118 python run_study.py --datasets Cora Citeseer Pubmed Physics Flickr --models GCN GAT GraphSAGE --attacks GTA UGBA DPGBA --seeds 10 20 30 --methods none abp rigbd dshield mad prune --rate 3 --class-sampling uneven --output-root outputs/server_native --device cuda:0
uv run --locked --extra cu118 python run_study.py --datasets Cora Citeseer Pubmed Physics Flickr --models GCN GAT GraphSAGE --attacks GTA UGBA DPGBA --seeds 10 20 30 --methods losplit --rate 3 --class-sampling uneven --output-root outputs/server_losplit_cpu --device cpu
```

第二条会在其输出目录重新生成样本。若要严格共用第一条的已保存样本，按组合逐次调用`run_defense.py --bundle 第一条对应的样本目录`，如第一节所示；不可把两个独立生成运行在不同设备上的样本当成逐文件相同。`run_study.py`的`--bundle`适合单数据集/单攻击/单种子固定样本的多骨架运行，不应给多组合批次传入同一固定样本目录。

DPGBA、GTA及大图路径已保留。原作者路径中的运行错误会如实记录；本轮只运行Cora验证，不代表所有数据/攻击/骨架组合都已训练成功。详见作者实现接入记录。

## 三、作者参数

`configs/author_parameters.json`保存每种作者原入口的默认值及公开脚本覆盖。优先级：原默认 → 数据/攻击公开覆盖 → `--author-overrides` → 专门的RIGBD/Prune覆盖参数。每次实际值写入`effective_parameters.json`，来源写入`result.json`。

| 参数 | 意义 |
|---|---|
| `--dataset` | Cora、Citeseer、Pubmed、Physics、Flickr |
| `--attack` | GTA、UGBA、DPGBA |
| `--model` | GCN、GAT、GraphSAGE，指最终模型；固定辅助模型保持作者设定 |
| `--methods` | none、abp、rigbd、losplit、dshield、mad、prune |
| `--seed` | 本次生成和作者入口外层种子；MAD另保留作者内部五种子 |
| `--split-seed` | 固定节点划分种子，默认10 |
| `--bundle` | 使用已经生成的样本包，包含training、evaluation、generator及metadata |
| `--vs_number`、`--vs-number` | 显式训练触发器选样预算，与rate二选一；选后滤原目标类，不补选 |
| `--rate` | 注入前原训练节点数的百分比，1表示1%；向下取整；选后过滤；无默认值 |
| `--class-sampling` | 默认random；uneven按seed为原始类别不均匀分配；两者均在选样后过滤原target类，再统一赋target |
| `--rigbd-k` | 覆盖RIGBD随机评分次数K；原始固定设置20 |
| `--rigbd-drop-ratio` | 覆盖RIGBD丢边比例；原始固定设置0.5 |
| `--prune-threshold` | 覆盖LoSplit原Prune阈值 |
| `--author-overrides` | JSON文件，使用各作者原参数名 |
| `--epochs/hidden/lr/dropout` | 无防御与ABP公共分类参数；作者方法使用作者配置 |
| `--resume` | 跳过当前协议下参数一致、模型散列一致的已完成运行 |

作者覆盖示例文件：

```json
{
  "rigbd": {"epochs": 1000},
  "losplit": {"split_epoch": 100},
  "dshield": {"dshield_classify_rounds": 1},
  "mad": {"dist_thrd": 3.0, "fluctuation_thrd": 0.015}
}
```

这只是展示原参数名的写法。覆盖参数属于本次实验选择，结果不会标成作者最佳配置。DShield公开单攻击命令仅对部分组合给出，其他组合原默认可能为100个分类轮次，运行前查看实际配置。

```text
uv run --locked --extra cu118 python run_defense.py --methods rigbd --rigbd-k 50 --rigbd-drop-ratio 0.7 --bundle outputs/new_run/data/Cora/UGBA/seed10 --output-root outputs/rigbd_candidate
```

上例的50/0.7是候选配置；尚未找到作者按每个数据集/攻击公开的最佳K和丢边率表。

## 四、普通训练与单独重载

```text
uv run --locked --extra cu118 python train_model.py --data clean --dataset Cora --model GCN --output-root outputs/clean_run
uv run --locked --extra cu118 python train_model.py --data backdoor --dataset Cora --attack UGBA --bundle outputs/new_run/data/Cora/UGBA/seed10 --output-root outputs/plain_run
uv run --locked --extra cu118 python run_defense.py --bundle outputs/new_run/data/Cora/UGBA/seed10 --checkpoint outputs/new_run/runs/Cora/UGBA/seed10/GCN/rigbd/model.pt --output-root outputs/reload --device cuda:0
```

重载评估使用保存的原生模型和原预测代码，不重新训练；MAD加载全部五个模型和两个辅助模型。精确复核保持与训练记录相同的设备。
