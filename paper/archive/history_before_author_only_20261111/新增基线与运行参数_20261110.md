# 新增基线与运行参数

日期：2026-11-10。

## 1. 当前可选方法

--methods支持none、abp、rigbd、losplit、dshield、rs、abl、prune。默认保持原五种，新方法按需显式添加。

| 名称 | 本项目执行的操作 | 来源及适配 |
|---|---|---|
| rs | 每轮丢边训练；每张完整评估图独立抽20次，采用多数投票 | RIGBD论文的结构RS路线和作者采样原语；修正旧包装器GCN返回值、重复删边和单次预测问题 |
| abl | 逐节点LGA、低损失隔离、普通组微调、GGA遗忘 | NeurIPS 2021 ABL作者实现与论文目标的GNN适配；保留原源码，使用项目三种GNN和Adam |
| prune | 根据特征余弦相似度筛边；训练和每张评估图分别处理 | RIGBD作者prune_unrelated_edge函数，严格保留cosine>阈值 |

RS名称对应不同实现：本项目rs明确表示结构丢边版本。DShield文中介绍的节点采样／特征遮蔽路线没有混入这一名称。LoSplit主对比表包含ABL和Prune，没有独立RS结果行。

ABL默认LGA50轮、阈值0.5，隔离训练节点的1%；普通微调使用公共epochs，随后5轮GGA，遗忘学习率0.0005。隔离比例不读取真实污染数量。旧图源码中被注释的LGA和截为零的遗忘项按完整算法补齐，因此本项目命名为论文目标图适配。

RS默认丢边率0.7、投票20次；其推理成本单独计入reference_inference_seconds和triggered_inference_seconds。build_plus_inference_seconds为建立模型与两次规定图预测的合计。

Prune默认阈值0.5，可通过--prune-threshold指定。调整参数时使用验证集，完整记录参数。

## 2. RIGBD当前协议

- 默认--rigbd-probe-checkpoint author：GCN评分器取末轮，GAT／GraphSAGE取最佳验证轮，与作者实际训练函数对应。
- 默认--rigbd-sampling incoming：按GNN消息接收端恢复丢空的邻域。
- --rigbd-sampling author：保留作者按出度恢复的实现，用于原代码参照。
- --rigbd-sampling paired：无向边配对删除与双向恢复，作为单列变体。
- --rigbd-loss source：保留作者概率惩罚恢复；paper为对数目标，二者分别报告。
- 三种最终骨架仍使用对应骨架评分；项目采用公开入口的骨架路线。GAT自环和GraphSAGE自身分量按实际层配置记录。

旧项目版本重播GCN评分时，使用--rigbd-probe-checkpoint best_validation --rigbd-sampling author。正式未知信息条件下不提供真实目标、真实数量或真实附着名单。

## 3. vs_number的对应关系

下面三个参数完全等价，均写入args.poison_count：

```text
--poison-count 40
--vs-number 40
--vs_number 40
```

它表示选择40个原节点附着触发，不是新增40个节点。trigger_size=3时通常新增120个训练触发节点。显式数量优先于poison_fraction；本项目直接指定数量即可启用，不需要额外的use_vs_number开关。

默认仍是原节点总数的1%：Cora为27，Citeseer为33。作者部分入口的vs_ratio以非测试原节点数为分母；两种比例数值不可直接互换。某些作者入口还会排除原目标类节点，或直接读取既有名单；最终数量应查实际保存数据。

该参数只控制新生成样本。读取既有bundle时，实际附着数量以metadata.json和样本内容为准，单独改防御参数不会改变图。

## 4. Cora运行示例

生成指定数量的Cora样本：

```text
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack DPGBA --vs_number 40 --seed 10 --output-root outputs/cora_count40
```

在固定样本上比较全部八种方法：

```text
uv run --locked --extra cu118 python run_defense.py --dataset Cora --attack DPGBA --model GCN --bundle outputs/cora_count40/data/Cora/DPGBA/seed10 --methods none abp rigbd losplit dshield rs abl prune --rigbd-sampling incoming --output-root outputs/cora_all_methods_v2
```

切换GAT或GraphSAGE时修改--model，所有方法继续读取同一个bundle。

只核查服务器已有文件，不执行训练：

```text
uv run --locked --extra cu118 python audit_saved_results.py --root outputs/server_extra --output paper/server_flow_audit.json
```

只用Cora进行RIGBD分阶段控制实验：

```text
uv run --locked --extra cu118 python audit_cora_rigbd.py --bundle outputs/cora_count40/data/Cora/DPGBA/seed10 --output outputs/cora_rigbd_control --models GCN GAT GraphSAGE --seed 10 --hidden 64 --epochs 400 --probe-epochs 1000 --repeats 20
```

该诊断目录中uses_evaluator_truth=true的行使用真实名单／数量进行定位，独立于正式方法对照。新版本使用新的输出目录，原结果继续保留。汇总按参数、源码和环境的protocol_id分别统计。
