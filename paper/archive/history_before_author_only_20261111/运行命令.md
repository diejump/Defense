# 运行命令与参数

2026-11-10修正后的RIGBD协议、RS／ABL／Prune及vs_number说明见[新增基线与运行参数](新增基线与运行参数_20261110.md)。默认RIGBD评分检查点为author，默认孤立恢复按消息接收端incoming；需要作者原采样时显式选择author。

以下命令在项目根目录执行。Windows进入D:\GNNAttackReaserch\abp；服务器进入复制后的abp目录。

## 1. 环境与公开数据

```text
uv sync --locked --extra cu118
uv run --locked --extra cu118 python prepare_data.py --datasets Cora Citeseer Pubmed
```

无GPU时将extra换成cpu，并在实验命令中设置--device cpu。Physics、Flickr也可用prepare_data.py准备，由PyG下载对应公开数据。

本地本轮复用已经配置好的解释器D:\GNNAttackReaserch\gnn_defense_study_20261029\.venv\Scripts\python.exe。新项目不导入旧项目的bmr；服务器按新目录的锁文件建立自己的环境。

## 2. 一条命令完成比较

```text
uv run --locked --extra cu118 python run_study.py --datasets Cora Citeseer --models GCN GAT GraphSAGE --attacks UGBA --seeds 10 --output-root outputs/main_ugba
```

默认方法为none、abp、rigbd、losplit、dshield。相同数据／生成算法／种子只生成一次，三个骨架共用。所有训练完成后汇总summary.csv、summary.md和summary_statistics.json。

如进程中断，使用原命令追加--resume。已完成且参数相同的模型跳过；失败记录保留，修改参数后使用新的输出目录。

## 3. 逐阶段执行

先生成固定样本：

```text
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack UGBA --seed 10 --output-root outputs/demo
```

生成时同时训练一个GAT无防御模型，计算该骨架的参考CA和ASR：

```text
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack UGBA --seed 10 --model GAT --evaluate --output-root outputs/demo
```

在同一份样本上执行防御：

```text
uv run --locked --extra cu118 python run_defense.py --dataset Cora --attack UGBA --seed 10 --model GAT --methods none abp rigbd losplit dshield --output-root outputs/demo
```

训练正常图模型：

```text
uv run --locked --extra cu118 python train_model.py --data clean --dataset Cora --model GCN --seed 10 --output-root outputs/clean_reference
```

训练污染图上的普通模型：

```text
uv run --locked --extra cu118 python train_model.py --data backdoor --dataset Cora --attack UGBA --model GCN --seed 10 --bundle outputs/demo/data/Cora/UGBA/seed10 --output-root outputs/ordinary_reference
```

重载已保存的ABP模型：

```text
uv run --locked --extra cu118 python run_defense.py --bundle outputs/demo/data/Cora/UGBA/seed10 --checkpoint outputs/demo/runs/Cora/UGBA/seed10/GAT/abp/model.pt --output-root outputs/reload
```

重载输出reevaluation.json，模型与样本ID在评估前核对。

## 4. 服务器上的剩余组合

Cora、Citeseer上的GTA和DPGBA：

```text
uv run --locked --extra cu118 python run_study.py --datasets Cora Citeseer --models GCN GAT GraphSAGE --attacks GTA DPGBA --seeds 10 11 12 13 14 --output-root outputs/server_extra
```

Pubmed、Physics、Flickr上的全部生成算法：

```text
uv run --locked --extra cu118 python prepare_data.py --datasets Pubmed Physics Flickr
uv run --locked --extra cu118 python run_study.py --datasets Pubmed Physics Flickr --models GCN GAT GraphSAGE --attacks GTA UGBA DPGBA --seeds 10 11 12 13 14 --output-root outputs/server_large
```

仅检查一个较大数据的接口或资源占用时，可先设--datasets Physics --models GCN --attacks UGBA --seeds 10 --methods none abp。作者模型采用整图训练，隐藏宽度通过--hidden统一设置，代码不会自动切换骨架或减少样本。

## 5. 常用参数

| 参数 | 默认值 | 作用 |
|---|---|---|
| --dataset、--model、--attack | Cora、GCN、UGBA | 单阶段的组合 |
| --datasets、--models、--attacks | Cora Citeseer；三骨架；UGBA | 批量组合列表 |
| --seed、--seeds | 10 | 生成及分类训练种子 |
| --split-seed | 10 | 固定划分种子，多生成种子仍共用该划分 |
| --methods | none abp rigbd losplit dshield | 方法列表 |
| --hidden、--epochs | 64、400 | 所有最终模型的公共训练设置 |
| --lr、--dropout、--weight-decay | .01、.5、.0005 | 公共分类设置 |
| --poison-fraction | .01 | 附着数占原节点总数的比例 |
| --poison-count | 未设置 | 显式数量，设置后覆盖比例 |
| --trigger-size、--target | 3、0 | 每组新增节点数及目标类别 |
| --attack-epochs、--attack-hidden | 400、32 | 生成器设置 |
| --attack-inner、--target-weight | 按生成器选择 | UGBA为5/5，DPGBA为1/1 |
| --rigbd-probe-epochs、--rigbd-repeats | 1000、20 | 同骨架准备训练及评分次数 |
| --rigbd-loss | source | 源码式概率目标；paper为论文式目标 |
| --losplit-epochs、--losplit-lr、--losplit-gamma | 作者按数据／攻击给定的配置 | 显式提供则覆盖默认 |
| --losplit-loss | source | 源码等价恢复；paper为论文公式恢复 |
| --dshield-pretrain、--dshield-finetune | 400、400 | 自监督及关系验证轮数 |
| --dshield-rounds | 1 | DShield防御轮数 |
| --device | cuda:0 | 设备 |
| --bundle | 自动路径 | 直接指定固定样本目录 |
| --data-root、--output-root | data、outputs | 输入缓存与输出位置 |
| --resume | 默认关闭 | 跳过已经完成且参数一致的运行 |

所有参数的说明可用对应入口的--help查看。IDE手动运行时可修改src/config.py默认值。

## 6. 保存位置

- data/<数据集>/raw：公开原始数据。
- <output-root>/data/<数据集>/<攻击>/seed<种子>：training.pt、evaluation.pt、generator.pt、metadata.json。
- <output-root>/runs/<数据集>/<攻击>/seed<种子>/<骨架>/<方法>：model.pt和result.json。
- <output-root>/summary.csv、summary.md：全部完成记录。
- <output-root>/summary_statistics.json：实际种子均值、样本标准差，单种子标准差为空。

只需重新汇总时：

```text
uv run --locked --extra cu118 python summarize.py --output-root outputs/main_ugba
```

检查代码与接口时：

```text
uv run --locked --extra cu118 python check_project.py
```
