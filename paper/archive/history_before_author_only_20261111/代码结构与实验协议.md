## 1. 阅读顺序

先读run_study.py，再读src/workflow.py。前者安排实验组合，后者依次读取训练样本、训练一个方法、保存模型、评估并保存指标。

| 文件 | 具体作用 |
|---|---|
| prepare_data.py | 下载和读取公开数据，记录原始文件散列 |
| run_attack.py、src/attack.py | 调用作者生成算法，保存固定训练图和测试图 |
| train_model.py | 单独训练正常图或污染图上的普通模型 |
| run_defense.py、src/workflow.py | 执行所选方法，或重载模型评估 |
| src/models.py | 明确选择三位作者的GCN、GAT、GraphSAGE |
| src/training.py | 普通分类训练和验证集选择 |
| src/abp.py | 按ABP规则处理信息传递方向 |
| src/rigbd.py | 同骨架评分、自动筛选和恢复 |
| src/losplit.py | 固定GCN分组，再以所选骨架恢复 |
| src/dshield.py | 准备模型、补齐未知标签、调用作者DShield |
| src/evaluation.py | 读取测试真值，计算CA、ASR和必要计数 |
| summarize.py、src/summary.py | 从真实记录生成CSV、Markdown和多种子统计 |
| upstream | RIGBD、LoSplit、DShield源码，各一份 |

普通流程重新编写；作者模型、LoSplit划分器、DShield主体和三种生成算法保留来源。来源提交、复制记录及导入修改在SOURCE_COPY_RECORD.json、作者源码导入改动.patch中。

## 2. 三个方法的骨架关系

| 方法 | 评分／准备阶段 | 最终分类阶段 |
|---|---|---|
| 无防御、ABP | ABP先处理连接，无额外评分模型 | RIGBD仓库中的所选GCN／GAT／GraphSAGE |
| RIGBD | 所选GCN／GAT／GraphSAGE，1000轮 | 相同骨架，400轮 |
| LoSplit | 作者LoSplit类，内部固定GCN，早期分组 | 所选GCN／GAT／GraphSAGE，400轮 |
| DShield | 作者对应分类模型；内部编码器按arch选择 | 作者对应骨架恢复，400轮 |

RIGBD作者构造器的add_self_loops=False只传给GCN。GAT评分模型仍采用默认自环；GraphSAGE保留自身根分量。新项目逐项记录实际层设置。

最终隐藏宽度统一64，GAT为8头、每头64。DShield保留作者内部编码器的头数与投影维数，以及原始分数输出；RIGBD和LoSplit返回log-softmax。相同骨架名称对应各作者的实现，具体类、层配置和参数量写入每次result.json。

## 3. 数据与样本生成

- Cora、Citeseer、Pubmed：PyG Planetoid，公开原始文件来自kimiyoung/planetoid。
- Physics：PyG Coauthor的Physics数据。
- Flickr：PyG Flickr。
- 前四种数据逐行NormalizeFeatures；Flickr按DShield入口逐列min-max。
- 固定split_seed=10，训练20%、验证10%、测试20%；测试索引前半用于CA，后半用于添加测试触发。
- 训练附着节点从剩余未标注节点中随机选择，排除训练、验证和测试集合。默认数量为原节点总数1%，新增3节点，目标类0。
- 三种生成器均直接调用DShield仓库版本，辅助模型固定GCN。UGBA默认生成器400轮、内部5轮、隐藏32、目标损失权重5、相似性损失权重100；实际参数逐项存档。
- 最终生成入口只传入训练节点标签；GTA目标类样本据此从训练集选择。UGBA的训练监督读取范围已用同初始化、完整标签／隐藏未知标签两次训练的权重逐项一致性检查核验。
- 同一数据集、生成方法和种子只生成一份资料，三骨架与全部方法共用。先向全部攻击测试索引加入触发，再按非目标类节点计算ASR。
- 所有零权连接都物理移除，避免GAT和GraphSAGE忽略边权后保留无效连接。

training.pt只保存可用训练／验证标签，未知原节点为-1；evaluation.pt保存测试真值和真实附着位置。标签向量保持原节点数，新增节点没有标签槽位，与作者DShield小图属性梯度接口一致。

DShield需要为原节点计算属性梯度，未知原节点用准备模型预测补齐，训练和验证标签保留。作者入口使用完整标签，新项目采用可用标签与伪标签的统一输入条件。

## 4. 恢复训练的源码模式与论文模式

RIGBD默认source模式：正常组交叉熵均值，加候选组各自已有标签概率均值。正常组与候选组通过节点编号值做差集，修正Tensor集合差集问题。末轮参数作为最终模型。paper模式改用论文的对数目标项。

LoSplit默认source模式：正常组交叉熵总和，加gamma乘候选替代标签交叉熵总和，再除以全部训练节点数。替代标签在训练前抽一次，排除推断目标类。这与作者有限数值下的实际源码目标等价：源码relu(-NLL)为零。实现使用独立替代标签，保持原训练标签不被别名写入。paper模式每轮重抽替代标签，并加入论文的遗忘项。两个模式分开记录。

LoSplit使用作者defense.sh按数据集／生成算法提供的早期参数，已覆盖Cora、Citeseer、Pubmed、Physics和Flickr。11月10日核查补齐了后两种数据集原本已存在的公开参数，支持命令行覆盖。

DShield默认kappa1/2=5、kappa3=0.1，丢边／丢特征0.2，温度0.9，平衡0.5，一轮防御，阈值2.5；自监督和关系验证各400轮。Cora公开命令支持这组系数；Citeseer、Physics等扩展组合的默认系数作为统一实验设置记录。

## 5. 指标和时间

CA是未额外加入测试触发的参考图上正常测试节点准确率。ASR是触发图中原标签不同于目标类的测试节点被判为目标类的比例。另存触发整图CA、整数分子与分母，便于核对作者口径。

建立模型时间从训练数据驻设备后、创建模型前开始，到方法返回可用模型结束，包含必要准备、评分、图处理和最终训练。两端GPU同步，使用perf_counter。读取样本、模型保存、测试推理和结果写盘单独处理。

ABP每张测试图的处理包含在对应推理时间内。ABP没有独立的节点检测名单；保存旧分类改变数。其他方法的选择名单仅在评估完成后与真实位置核对。

本地任务为一个种子10、六个数据／骨架组合，每方法单次运行；主要报告逐组合CA、ASR与时间。多种子均值和样本标准差由实际记录汇总。原生GPU运行保留随机种子，数值执行使用PyG原生路径。

## 6. 数据与源码复核

每个样本包记录参数、数据来源和文件散列。每次方法运行记录样本ID、源码散列、实际模型、参数量、阶段时间和模型散列。模型重载先核对样本ID。

Physics为新增数据接口；Flickr沿用作者数据读取和归一化。两者以及GTA、DPGBA完整规模实验交由服务器执行，本地另做小规模接口核查。

## 7. 本地记录与最终代码

本地30次方法运行完成后，补充了预测有限值检查、环境字段和生成标签范围检查。原始result.json保留各次实际代码散列。verify_results.py用最终代码重新加载全部权重，核对整数分子、分母和ABP分类改变数，记录源文件更新列表。

本地UGBA样本生成时使用的完整原节点标签向量，其损失实际只读取训练标签及被覆盖为目标类别的外层标签。最终入口显式隐藏未知标签；单元检查验证这一变化在相同初始化下生成权重逐项相同。固定样本和原始指标均保持原值。
