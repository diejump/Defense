# RIGBD参数依据与原作者入口复用记录

日期：2026-11-11。

## 1. 已证实的参数与未公开的信息

目前没有找到RIGBD或LoSplit作者公开的“数据集＋攻击方法→RIGBD最佳K和drop_ratio”表，不能替作者补写最佳组合。

| 作者位置 | 实际公开内容 | 应如何描述 |
|---|---|---|
| RIGBD `defense.py:231、266` | drop_ratio=.5、K=20 | 原始固定设置 |
| RIGBD `README.md` | Cora、PubMed、ogbn-arxiv示例，未按组合覆盖K/drop | 运行示例，不是最佳参数映射 |
| RIGBD `script/train_defense.sh:1` | Cora、vs_number40 | 没有新增K/drop依据 |
| LoSplit `UGBA_RIGBD.py:297–302` | K=[25,50,100]；drop=[.3,.5,.7,.9] | 候选网格 |
| LoSplit `GTA_RIGBD.py:277–282` | K=[10,20,25,50]；drop=[.3,.5,.7,.9] | 候选网格 |
| LoSplit `SPEAR_RIGBD.py:236–241` | K=[50,100]；drop=[.5,.7,.9] | 候选网格 |
| LoSplit `DPGBA/DPGBA_RIGBD.py:284–290` | K=[2,5,25,50,100]；drop=[.1,.3,.5,.7,.9] | 候选网格 |

LoSplit `defense.sh`按数据集安排的 `split_lr/split_epoch/gamma` 是LoSplit划分及恢复参数，不能转写为RIGBD的K/drop。DPGBA命令里的小写 `--k` 是生成算法参数，也不是RIGBD评分重复次数。

本项目的作者调用模块仅将原RIGBD的两个常量参数化为 `args.K`、`args.drop_ratio`。原始固定配置仍为20/.5；其他值只能标记为用户指定值或公开网格中的候选，不能标记为已核验的作者最佳值。

## 2. 唯一作者流程

本轮不提供论文式／修正式恢复分支。`src/author_methods/rigbd.py`抽取原 `upstream/RIGBD/defense.py`中污染资料准备完成后的参考评估和完整防御代码。

- 保留参考模型构造、原生 `.fit()`和参考推理，再训练评分模型。参考阶段没有省略，也没有在防御前额外重新设置随机种子。
- 保留 `model_construct(..., add_self_loops=False)`的实际骨架行为：该开关仅由工厂传给GCN。GAT与GraphSage保持原模型处理。
- 原样提升 `sample_noise_all`及 `find_index`到模块级；采样仍按发送端连接数恢复原有连接方向。
- `find_index`仍接收 `args.target_class`，保留 `return i-1`及原切片。没有改为最高分标签推断或严格分数阈值。
- 最终仍调用原模型 `.fit(..., train_iters=400, finetune=True, attach=...)`，由作者的 `fientune`执行恢复。没有自写训练损失或额外检查点规则。
- 普通模型训练也直接经过原 `.fit()`。原GCN末轮、GAT／GraphSage最佳验证状态及GAT额外初始化等差异均由原模型执行。
- 保留作者现有Tensor集合差集、报告切片、空候选等行为。若原语句报错，运行应记录阻塞，不能填入预期结果或转用其他版本。

源码原打印的 `correct`是标签等于目标类的计数，不能直接称为真实附着TP；原打印统计切片也与实际恢复切片相差一位。ASR与检测召回率保持不同含义。

## 3. LoSplit按原攻击分支调用

| 适配模块 | 原入口 | 隔离导入根目录 |
|---|---|---|
| `losplit_gta.py` | `upstream/LoSplit/GTA_LoSplit.py` | `upstream/LoSplit` |
| `losplit_ugba.py` | `upstream/LoSplit/UGBA_LoSplit.py` | `upstream/LoSplit` |
| `losplit_dpgba.py` | `upstream/LoSplit/DPGBA/DPGBA_LoSplit.py` | `upstream/LoSplit/DPGBA` |

三个调用模块均保留污染图取得后的原参考训练／评估、LoSplit划分、`max(deltas[1:])`选择、原材料保存以及200轮原生 `finetune2`。没有复制根目录模型到DPGBA分支，没有重新实现公式，也没有修正原标签别名或损失截断语义。

DPGBA原入口的 `models=['GCN']`仅参数化为 `[requested_model]`，保留原for循环及其中的构造、训练、CPU搬移和缓存处理顺序。该变动是骨架配置参数化，实际使用的模型名保存在返回的 `source_args`中。若对应作者模型内部存在返回值不匹配等问题，保留真实报错，不改用根分支或其他实现。

## 4. 外层接口与计时

统一入口为 `run(inputs,args,device)`。输入绑定到作者原变量名；不排序附着名单，不复制或修正训练标签。

允许的外层适配只有：输入绑定、K/drop与模型列表参数化、把原先外层Tensor/Tuple输出通过 `logits_of`取分类分数、阶段计时与结果封装。原模型函数内部的计算和错误均保持原样。

RIGBD抽取片段中没有执行任何Prune语句，因此没有复制原入口未使用的 `help_funcs`导入，避免为无用导入增加依赖；原模型工厂导入仍保留。三个LoSplit调用模块保留原 `help_funcs`中的直接Prune函数导入。

- `reference_seconds`：作者参考阶段。
- `model_build_seconds`：作者防御模型构造、评分／划分及最终训练；LoSplit保存材料的文件写入不计入此项。
- `prediction_seconds`：作者最终推理及其指标处理。
- `internal_seeds=[]`：抽取从原入口设置种子及生成准备之后开始；该片段内没有额外播种。外层工作进程负责按作者种子配置开始，不能在参考与防御之间重置种子。

返回的 `models`只包含最终原生对象，`auxiliary_models={}`。RIGBD的CA来自已经注入测试触发的整图；LoSplit的CA来自恢复测试关联边但尚未注入测试触发的图。`source_metrics`逐项记录这些范围，不将不同范围的CA混作同一定义。
